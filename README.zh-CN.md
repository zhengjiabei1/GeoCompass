# GeoSkillCompass

**面向地理空间智能体的校准式空间技能复用与分层经验记忆。**

LLM 正在被用作地理空间智能体，负责规划并调用 GIS 与遥感工具。一个常见失败是**负迁移**：在某一类任务上有效的空间分析技能，被错误地复用到不兼容的任务上，智能体却不会主动发现。GeoSkillCompass 关注一个简单问题：

> 地理空间智能体应该在什么时候复用已有的空间分析技能，什么时候应该探索新技能？

本仓库包含一个确定性、CPU 可运行的基准，一个校准式复用判别器，一个迁移门控，以及一个分层经验记忆。所有报告数字都由仓库内的实验脚本生成。

## 方法

| 组件 | 作用 |
|---|---|
| **空间技能库** | 覆盖土地覆盖、作物、水体、洪水、变化检测、城市扩张、火烧迹地的专家流程。每个技能声明目标、输入类型、光谱机制与成本。 |
| **候选检索** | 在执行前用语义与结构特征召回一小批候选技能。 |
| **校准式复用判别器** | 在任务—技能结构特征上做逻辑回归，并用温度缩放或等渗回归校准。它在执行前估计技能成功概率。 |
| **迁移门控** | 用 Beta-二项分布诊断源任务到目标任务的迁移性，阻断低期望效用的技能，降低负迁移。 |
| **分层经验记忆** | 短期与长期经验存储，带去重。相比扁平回放缓存，只用约六分之一存储。 |

核心设计是把两个常被相似度检索混在一起的问题分开：

1. **这个技能和任务相关吗？**（语义与结构匹配）
2. **我有多大把握它在这里会成功？**（校准后的结果概率与迁移证据）

## 基准

基准生成合成的多波段场景，包含六个光谱波段（`blue`、`green`、`red`、`nir`、`swir1`、`swir2`）和七类任务：

- `landcover`：六类土地覆盖制图
- `crop`：作物/非作物制图
- `water`：水体提取
- `flood`：洪水制图
- `change`：双时相变化检测
- `urban`：城市扩张检测
- `burn`：火烧迹地检测

场景在区域、季节、云量和分辨率上变化。生成器确定性、CPU 可运行。真实 GeoTIFF 可以通过 `geoskillcompass.raster.load_geotiff` 接入。

## 结果

运行设置：3 个 seed，每个 seed 70 个源训练任务和 42 个目标测试任务，20 个技能的技能库，CPU 运行，耗时 664 秒。

| 方法 | 成功率 | AUROC | ECE | 负迁移 |
|---|---:|---:|---:|---:|
| 语义检索 | 0.500 | 0.666 | 0.152 | 0.183 |
| 逻辑回归判别器 | 0.683 | 0.842 | 0.121 | 0.056 |
| 加等渗校准 | 0.675 | 0.842 | 0.063 | 0.056 |
| 加迁移门控 | **0.698** | **0.842** | **0.063** | **0.048** |

分层记忆，前序流式评估：

| 记忆模式 | 成功率 | ECE | 保留记录 | 字符数 |
|---|---:|---:|---:|---:|
| 无记忆 | 0.774 | 0.232 | 0 | 0 |
| 扁平记忆 | 0.780 | 0.113 | 616 | 57,315 |
| 分层记忆 | 0.780 | 0.131 | 106 | 9,535 |

**主要发现**

- 校准把 AUROC 从 0.666 提升到 0.842，并把 ECE 从 0.152 降到 0.063。
- 迁移门控把成功率从 0.675 提升到 0.698，并把负迁移从 0.056 降到 0.048。
- 分层记忆在保持 0.780 成功率的同时，字符数约为扁平记忆的六分之一（9,535 对 57,315）。
- 预算重试可把成功率推到 0.746，但负迁移升到 0.286；门控是更稳的工作点。

完整表格和图见 [`experiments/geoskillcompass/REPORT.md`](experiments/geoskillcompass/REPORT.md)。

## 复现

```bash
python -m geoskillcompass experiment --seeds 0,1,2 --output experiments/geoskillcompass
python -m geoskillcompass report
```

运行后会在 `experiments/geoskillcompass/` 下生成 `results.json`、CSV 表格、SVG 图和 `REPORT.md`。

## 说明

- **无第三方依赖**：仅用 Python 标准库，方便在笔记本上复现。
- **确定性**：所有划分由 seed 派生，除 seeded 生成器外没有隐藏随机性。
- **合成基准**：把技能复用决策与数据下载、预处理噪声隔离开；同一接口可以指向真实 GeoTIFF 场景做真实世界复现。
- **负迁移是一等指标**：总是复用最相似技能的方法，平均看可能不错，但在不兼容任务族上会失败得很惨。
